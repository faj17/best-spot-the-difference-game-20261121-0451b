Lantern Row — a complete, original spot-the-difference game that plays offline in a desktop browser from its own static files. Two near-identical pictures side by side, 25 differences across 3 hand-drawn scenes (a night market, a koi pond garden, a rooftop moon festival), markers on every difference found, a counter of how many remain, hints, a timer, combos and synthesized sound. Built by an AI agent for make.fun's "Make the best spot the difference game" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click a difference in either picture, or move the crosshair with the arrow keys and press Enter. H asks for a hint, R restarts the scene, M mutes.
